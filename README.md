# MediSync 🩺

> **All your health in Sync** — An AI-powered personal health record platform that lets patients securely upload medical documents, auto-extract structured health data, and gain intelligent insights through predictive analytics.

---

## Features

- **Smart Document Ingestion** — Upload prescriptions, lab reports, discharge summaries, and X-rays. An AI agent extracts structured data (medications, diagnoses, dates) automatically via OCR + LLM.
- **Interactive Timeline** — All medical events are organized chronologically with source document traceability.
- **AI Health Summary** — On-demand natural language summaries of your health history, generated by an LLM agent.
- **Predictive Health Scoring** — Risk scoring and health predictions based on your conditions, medications, and lab results.
- **Body Map** — Click-to-explore anatomical map showing which regions have recorded conditions/symptoms.
- **Secure Sharing** — Generate time-limited, permissioned share links for doctors to view read-only health records.
- **Blockchain Audit Trail** — Document fingerprints registered for tamper-proof verification.
- **Dual-Backend Auth** — MongoDB-first with automatic SQLite fallback for zero-configuration local development.
- **Two-Layer Caching** — Frontend `localStorage` + backend SQLite cache ensures AI results load instantly on revisit.

---

## Tech Stack

| Layer | Technology |
|---|---|
| **Backend API** | FastAPI (Python) |
| **Database** | MongoDB (primary) + SQLite (fallback/medical data) |
| **Authentication** | JWT (python-jose) + bcrypt with SHA-256 pre-hashing |
| **AI Agents** | Ollama (local LLM) / OpenAI |
| **OCR** | Tesseract + pdf2image (Pillow) |
| **Frontend** | Vanilla HTML/CSS/JS (no framework) |
| **Blockchain** | Custom audit agent |

## Getting Started

### Prerequisites

- Python 3.10+
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) installed and on PATH
- [Ollama](https://ollama.ai) running locally (or an OpenAI API key)
- MongoDB (optional — falls back to SQLite automatically)

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/medisync.git
cd medisync

# Install Python dependencies
pip install -r requirements.txt

# Copy environment config
cp .env.example .env
# Edit .env with your credentials
```

### Configuration (`.env`)

```env
MONGO_URI=mongodb://localhost:27017       # Or your Atlas URI
MONGO_DB=medisync
JWT_SECRET=your-secret-key-here          # Change in production!
ACCESS_TOKEN_TTL_MINUTES=60
REFRESH_TOKEN_TTL_DAYS=30
BCRYPT_ROUNDS=10
```

### Run

```bash
uvicorn main:app --reload --port 8000
```

Then open **http://localhost:8000** in your browser. You will be redirected to the login screen automatically.

## API Overview

|--------|----------|-------------|

| `GET` | `/auth/me` | Get current user profile |

| `GET` | `/api/lab-results` | List lab results |
| `GET` | `/api/summary` | AI health summary (cached 24h) |
| `GET` | `/api/predictions` | AI health predictions (cached 48h) |
| `GET` | `/api/health-score` | Numeric health score |
| `GET` | `/api/bodymap` | Body region condition map |
| `POST` | `/api/chat` | Ask the health AI assistant |
| `POST` | `/api/share/create` | Create a share token for a doctor |
| `GET` | `/api/user` | Get full profile (SQLite) |
| `PUT` | `/api/user` | Update profile settings |

## Security Notes

- Passwords are SHA-256 pre-hashed before being passed to bcrypt, allowing unlimited password length.
- JWT tokens are stored as `httpOnly`, `SameSite=Strict` cookies — never exposed to JavaScript.
- Share tokens are time-limited and can be individually revoked.
- In production, replace `JWT_SECRET` with a cryptographically random 64-character string.
